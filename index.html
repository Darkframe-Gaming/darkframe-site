THE STUDIO

Shot in the dark

Darkframe is a small independent studio. Art direction, mathematics, engineering and audio all happen under one roof — which is how a team this size ships games that feel this considered.

01 ORIGINAL IP ONLY

No licensed brands, no re-skins. Every world, character and soundtrack is designed in-house, for the one game it lives in.

02 PROVABLE MATH

Every model is simulated across millions of rounds and locked at exactly 96.7% RTP. Rule proofs run by machine and round books are hash-verified — if we claim a mechanic, we can prove it.

03 CRAFT OVER VOLUME

We ship few games and finish them properly. A slot is a thousand frames seen one at a time — we consider every one.

THE METHOD

Developed, not assembled

Expose, develop, fix, print — the darkroom process, applied to game design.

01 EXPOSE

Concept & mechanics. A game starts as a twist that doesn't exist yet — a board that slides, sticks, detonates or develops. We prototype until the mechanic explains itself on screen.

02 DEVELOP

The math model. Custom simulation engines run millions of rounds, tuning weights until the model locks at exactly 96.7% RTP with the volatility curve the theme demands.

03 FIX

Verification. Machine-run rule proofs, hash-verified round books and external test passes fix the model in place — what you play is exactly what was simulated.

04 PRINT

Production. High-performance WebGL front ends, original Spine animation and audio, localised into 17 languages — then published on Stake.
