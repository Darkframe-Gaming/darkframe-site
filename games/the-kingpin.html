THE FEATURES

How it plays

One plane changes a spin. A runway full of them changes the night.

01 PLANE WILDS

The Plane wild expands to cover its entire reel and carries its own multiplier into every line it completes.

02 MULTIPLIER BOOST

A random Boost can step a landed Plane's multiplier up before the lines pay — the same wild, worth more.

03 THE RUN

Three, four or five Jaguar scatters open 10 free spins in which every Plane sticks to its reel for the rest of the round.

04 BIG RUN · MYTHIC RUN

Buy The Big Run for a ×10 multiplier floor, or The Mythic Run for a guaranteed Plane on the first spin. The Drop is a mystery entry.
